# 执行判断与失败修正

## 从请求到一组照片

先确认输入职责和目标，再做服装分析与选姿计划。已有稳定基准图可直接使用；教程展示的 Soul 2.0、F04、外模、三视图和演示比例是该案例的选择，并非所有任务的前置。身份图缺失且用户确实要求创建模特时，才进入人物准备；不能擅自把用户已有模特换成教程人物。

每套服装记录：廓形与长度、结构／开口／装饰、面料垂坠与硬挺、可见运动余量、商品关键细节、整体穿搭情绪。由这些可见事实决定动作幅度、重心、手臂是否遮住结构、眼神与表情；不要只按“裙子／裤子”套统一动作。

配对表至少包含：序号、服装、固定参考、动作复合 ID、景别、动作、视线、表情、配对理由、比例和像素。用户只要某一动作时不扩写成多套流程；没有要求均衡时，不额外改动其张数分配。

## 条件规则

| 条件 | 行动 | 依据与限制 |
|---|---|---|
| 长裙或窄身衣服限制运动，或动作会压住／遮住下摆 | 优先选可执行的小幅承重、回望、坐姿或上身动作；先看商品结构能否承受 | 视频约00:38–00:47；是服装相容性判断，不是“长裙一律不能大动作” |
| 门襟、流苏或肩线是卖点 | 至少安排能展示它的正面／局部主图，检查手臂、头发、配饰遮挡 | 视频约00:48–00:53；不为展示细节擅改衣服结构 |
| 用户要轻松／可爱或冷静／酷 | 在姿态、眼神和表情之间配对，避免固定笑脸或怒脸 | 视频约00:32–00:40与图文19；明示用户选择优先 |
| 同套衣多张照片越生越不像原模特或商品 | 停止链式继承，逐张从相同固定源重做有问题的那张 | 图文19；上一张成片不能冒充新基准 |
| 动作页是半身、特写、无头或缺腿裁片 | 维持已见景别，或换确有完整肢体的姿势；不从裁片发明画外身体 | 图文19；索引与实际像素都要看 |
| 出现头身比异常 | 对照固定身份／身体参考与原景别，检查选姿裁片和透视，定向修复一次 | 作者视频说明承认仍会出错；不承诺某句提示词可百分之百修正 |
| 表情虽然像示例却与服装情绪冲突 | 服装保持不动，优先修正表情强度、视线或动作配对 | 图文19和视频说明；不要把动作页的人脸一并迁移 |
| 已有结果但输出像素不符 | 核实际文件尺寸；在当前工具可做时修复，不能只改文件名或称“4K” | 视频约00:59–01:08；1024×1536／1536×1024仅为案例 |
| 想用外部 API 获得更大尺寸 | 先明确可用服务、输入、收费和授权；缺条件则保留当前可用输出或提示词 | 视频约00:59–01:03没有公开具体服务、密钥或接口实现 |
| 同一任务超时或结果不确定 | 先查询原任务，确认失败再决定重试 | 图文19；不重复触发可能扣费的任务 |

若用户明确需要改变动作参考的景别，可把近景裁片只用作上身手势或表情参考，再用另一张完整姿势及衣鞋参考支持全身构图。说明各自控制范围并标为组合方案，不声称复原了近景原图未见的下身动作；缺少支持时只暂停依赖该信息的部分。

## 完成的判据

照片逐张核身份与发型、商品结构和本色、人体解剖及头身比、裁边与景别、实际像素、眼神／表情与服装关系。核不同动作是否真正有区别，是否达到 N；再看整组背景、光线和色彩。导出成功、索引能查或接口返回成功不能替代这些检查。

修复一次仍不通过的图片列为缺额，说明具体问题与可恢复的一步；不无限抽图。原参考保留，修图只作用于待修项，避免让已合格照片反复漂移。
